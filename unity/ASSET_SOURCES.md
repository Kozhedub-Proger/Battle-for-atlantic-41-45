# Бесплатные модели для Unity-прототипа

Для замены временных процедурных корпусов выбран **LowPoly Ship Pack — Quaternius**.

Источник: https://opengameart.org/content/lowpoly-ship-pack
Лицензия: CC0 / public domain. В пакете есть несколько разных кораблей, поэтому для двух сторон можно взять две разные модели из одного проверенного источника.

Почему модели пока не закоммичены бинарниками: GitHub-коннектор в этой сессии пишет текстовые файлы, а исходный пакет распространяется ZIP (~3.9 MB). Код v0.3 специально отделяет механику башен/стволов/снарядов от корпуса, поэтому FBX/OBJ можно подменить без переписывания боевой логики.

## Требование к префабу корабля
- корень модели ставится так, чтобы `Y=0` был ватерлинией;
- `Turret_Yaw` вращается только вокруг Y;
- дочерний `Gun_Pitch` меняет угол возвышения;
- каждый ствол имеет отдельный `Muzzle_N`;
- один `Muzzle` = один физический `Projectile` при залпе.

Текущая тестовая конфигурация: 2 башни × 2 ствола = 4 независимых снаряда.
