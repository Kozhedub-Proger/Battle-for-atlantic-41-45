# Сражения в Атлантике 41–45

Чистый Unity-проект под **Unity 6.3 LTS (6000.3.22f1)**.

## Текущая цель

Первый вертикальный срез:

1. Реалистичный океан.
2. Два настоящих 3D-корабля по ватерлинии.
3. Свободная камера.
4. Затем — башни, стволы и отдельные снаряды.

## Первый запуск

1. Установить Unity 6.3 LTS `6000.3.22f1` через Unity Hub.
2. Запустить `START_UNITY_PROJECT.bat` из корня проекта.
3. Unity автоматически импортирует URP 17.3 и создаст базовую сцену `Assets/Scenes/Main.unity`.

Если точная версия Editor лежит не в стандартной папке Unity Hub, BAT попробует найти любую установленную Unity 6000.3.x.

## Модели

Корабли складываем в `Assets/Ships/`. Перед добавлением модели обязательно сохраняем автора, URL и лицензию в `Assets/Ships/SOURCES.md`.

## Важно

В этом репозитории нет файлов других проектов. Не переносить сюда код Shadow Fighter и других репозиториев.
